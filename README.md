# SDET Java Foundations

A hands-on Java learning repository for SDET and QA Automation fundamentals.

## Topics Covered
- Java development environment: JDK, JRE, and JVM
- Java syntax and the main method
- Variables and data types
- Integer overflow and type casting
- Test duration sum and average calculation
- Basic test scenarios and boundary-value testing

## Project Structure
- `src/com/ashok/basics/HelloSdet.java`
- `src/com/ashok/basics/Day2/J01TestDurations.java`

## Goal
Build strong Java fundamentals for SDET and automation testing roles.
